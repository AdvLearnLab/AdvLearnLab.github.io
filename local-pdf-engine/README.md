# PDF 转可编辑 Word 本地引擎

文件只在用户自己的 Windows 电脑上处理，不会上传至网站或第三方转换服务。

1. 首次使用双击 `install.bat`，等待独立环境和公式模型依赖安装完成；脚本会自动寻找系统或 Codex 自带的 Python。
2. 如果电脑上没有任何可用 Python，请安装 Python 3.10 以上版本并勾选 `Add Python to PATH`。
3. 以后使用网站转换前，只需双击 `start.bat`。
4. 看到 `Uvicorn running on http://127.0.0.1:8765` 后，保持窗口打开并回到网页转换。

模型和依赖安装后会保存在本机，不会每次重复下载。本地引擎会提取文字块、图片和数学公式，按页面阅读顺序重新排版；公式写入 Word 原生公式对象，不会把整页做成图片。

核心引擎可以直接处理 PDF 内嵌公式。需要识别扫描图片中的复杂公式时，可另行双击 `install-formulas.bat` 安装增强公式模型；它体积较大，但只需安装一次，不会阻塞核心引擎启动。
