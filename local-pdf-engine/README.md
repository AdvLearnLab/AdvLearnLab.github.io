# PDF 转可编辑 Word 本地引擎

文件只在用户自己的 Windows 电脑上处理，不会上传至网站或第三方转换服务。

1. 安装 Python 3.10 或 3.11。
2. 首次使用双击 `install.bat`，等待独立环境和公式模型依赖安装完成。
3. 以后使用网站转换前，只需双击 `start.bat`。
4. 看到 `Uvicorn running on http://127.0.0.1:8765` 后，保持窗口打开并回到网页转换。

模型和依赖安装后会保存在本机，不会每次重复下载。本地引擎会提取文字块、图片和数学公式，按页面阅读顺序重新排版；公式写入 Word 原生公式对象，不会把整页做成图片。
